## 배경 (Background)

강의 중 교수의 구두 설명은 슬라이드 PDF에 없는 내용인데 강의가 끝나면 사라진다. 이 도구는 그 설명을 로컬 STT로 남기되, 어느 PDF 페이지에 대한 설명이었는지까지 연결해 저장한다.

- 복습 시 "특정 페이지에서 나온 설명"을 되짚으려면 발화가 해당 PDF 페이지와 연결되어 저장돼야 한다.
- 강의 녹음은 외부로 내보내지 않는 완전 로컬 처리를 전제한다.
- 실행 환경·코드 현황 사실은 [survey.md](survey.md)에 정리했다.
- '실시간'의 의미 구분:
  - 이 문서에서 '실시간'은 강의 중 **페이지 넘김 추적(라이브 넘김 로깅)**을 뜻하고, 라이브 STT(강의 중 실시간 전사)는 후속 단계다.
  - 라이브 넘김 로깅이 MVP 필수인 근거: 녹음만으로는 슬라이드 전환 시점을 복원하기 어려워, 사후에 녹음만 들어서는 어느 슬라이드의 설명이었는지 판단하기 어렵다.
- 인터뷰에서 확정한 도구 형태:
  - 캡처와 STT를 분리한다: 캡처(녹음 + 실시간 페이지 넘김 로그)는 강의 중 CLI가 담당하고, STT와 노트 생성은 강의 종료 후 사후에 실행한다("사후 처리 MVP").
  - 넘김 로그는 실시간 캡처와 사후 편집 두 경로로 만들어진다:
    - `record`는 강의 중 마이크 녹음과 실시간 페이지 넘김의 단축키 타임스탬프 로깅을 수행하며, 이 실시간 넘김 로깅은 MVP 필수다.
    - 사후 태깅은 강의 후 오디오를 들으며 페이지 넘김 마커를 추가·수정하고, 용도는 (a) 실시간 로깅의 누락·오조작 넘김을 교정하는 것과 (b) 실시간 로깅을 못 한 녹음을 전량 수동 태깅으로 살리는 폴백이다.
    - 넘김 디바운스는 넘긴 뒤 3초 이내에 원래 슬라이드로 복귀하면 그 넘김 이벤트를 취소해 실수 넘김을 막으며, 3초는 기본값이고 정확한 임계값·구현 방식은 design에서 조정한다.
  - 노트 생성: `process`는 오디오를 로컬 STT로 세그먼트별 시작/끝 시각과 함께 전사하고, 교정된 넘김 로그의 시간축과 매핑해 페이지별 마크다운 노트를 생성한다.
    - 페이지와 발화의 연결은 페이지 넘김 타임스탬프 기준으로, 발화 시각이 속한 넘김 구간으로 페이지를 결정한다.
    - 결과물은 페이지별 `.md` 파일로 남긴다(파일 기반이라 검색·버전관리에 유리하다).
  - 인식 대상 언어는 한국어, 영어, 그리고 둘이 섞인 발화(코드 스위칭)를 포함한다.

## 제약 (Constraints)

- 로컬·오프라인 처리:
  - 녹음·STT·노트 생성을 포함한 모든 처리는 로컬에서 수행하고, 강의 녹음을 외부로 전송하지 않는다.
  - 대상 실행 환경은 개인 소유 M4 Pro Mac 1대이며, 세부 환경 사실은 [survey.md](survey.md)에 있다.
- 인식 범위:
  - STT는 한국어, 영어, 그리고 한 발화 안에서 둘이 섞이는 코드 스위칭을 인식해야 한다.
  - 강의실 마이크 환경(원거리·잡음)이 STT 정확도에 영향을 줄 수 있으나, 이 개선은 MVP 범위 밖이다.
- design으로 넘기는 세부:
  - STT 모델은 requirements 단계에서 확정하지 않고, design 단계 벤치마크 결과로 선정한다.
  - 오디오 장치·포맷·샘플레이트, STT 모델의 메모리·시간 예산, 넘김 입력 수단(전역 단축키 vs 터미널 키 입력), 디바운스 임계값·구현 방식은 design에서 정한다.

## 진행 단계 (Progress stages)

- 1단계 — 사후 처리 MVP: 강의 중에는 `record`로 캡처(녹음 + 실시간 페이지 넘김 로깅)만 하고, 강의 종료 후 사후 태깅으로 넘김을 교정한 뒤 `process`로 전사·매핑·노트 생성을 실행한다. 실시간 넘김 로깅과 사후 태깅 편집 모두 이 에픽의 완료 범위다.
- 2단계 — 라이브 STT 후속: 강의 중 실시간 전사(라이브 STT)는 MVP 이후 별도 자식 이슈로 다루며, 이 문서의 완료 범위에 포함하지 않는다. 1단계의 '실시간'은 페이지 넘김 추적을 뜻하고 라이브 STT와 구분된다.

## 마일스톤 (Milestones)

- STT 조사·선정: 로컬 실행 STT 후보를 한국어/영어/혼용 실제 음성으로 정확도·속도를 측정해 기록한 뒤 한 모델을 선정한다. design의 첫 작업 항목이다.
- 캡처(`record`): 마이크 녹음과 실시간 페이지 넘김 단축키의 타임스탬프 로깅을 구현하고, 3초 디바운스 원복 규칙을 포함해, 오디오 파일과 넘김 로그를 산출한다.
- 사후 태깅 편집: 강의 후 오디오를 들으며 페이지 넘김 마커를 추가·수정하는 경로를 구현해, 실시간 로깅을 교정하거나 로깅이 없는 녹음을 수동 태깅으로 살린다.
- 사후 처리(`process`)·매핑·노트 생성: 선정된 STT로 세그먼트별 시각과 함께 전사하고, 교정된 넘김 로그 시간축과 매핑해, 페이지별 `.md` 노트를 생성한다.

## 블로커 (Blockers)

- 넘김 기록 UX 리스크(완화됨): 강의 중 노트북으로 PDF를 넘기면서 동시에 CLI 단축키로 넘김을 기록하는 흐름에 넘김 누락·오조작 가능성은 남지만, 사후 태깅 폴백으로 강의 후 전량 교정·재구성이 가능해 리스크 수위는 낮아졌다. 입력 수단의 구체안은 design 판단 사항이다.
- 의존: STT 모델은 design 벤치마크로 선정되므로, 그 전까지 정확도·속도 목표를 수치로 확정할 수 없다.

## 테스트 계획 (Test plan)

- STT 선정 벤치마크: 한국어/영어/혼용 실제 강의성 음성 샘플로 후보별 전사 정확도와 처리 속도를 측정·비교한다.
- 페이지 매핑 검증: 알려진 넘김 시각과 발화 시각으로 각 세그먼트가 올바른 페이지 구간에 배정되는지 확인한다(구간 경계 시각 포함).
- 디바운스 원복 검증: 넘긴 뒤 3초 이내에 원래 슬라이드로 복귀하면 넘김이 취소되고, 3초 이후에 복귀하면 별개 넘김으로 유지되는지 확인한다.
- 사후 태깅 반영 검증: 사후 태깅으로 넘김을 추가·수정한 뒤 그 변경이 `process`의 페이지 매핑 결과에 반영되는지 확인한다.
- 산출물 검증: `process` 결과가 페이지별 `.md` 파일로 생성되고, 각 파일이 해당 페이지 구간의 발화 텍스트를 담는지 확인한다.
- 언어 혼용 처리: 코드 스위칭 발화가 유실 없이 전사되는지 확인한다.
